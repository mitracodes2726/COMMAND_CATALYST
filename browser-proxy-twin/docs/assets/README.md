# Assets to add before submitting

- `pitch-deck.pdf`: export your PowerPoint (File > Export > PDF).
- `demo.gif`: a short screen recording of `./run_demo.sh` (for example with ScreenToGif or OBS).
- Optional: `demo-video-link.txt` with your YouTube link.

Then reference them in the README, for example: `![demo](docs/assets/demo.gif)`.
